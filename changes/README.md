# Запросы на изменение макета

Изменение макета после сдачи — не правка «по месту», а запрос: что изменилось,
какие секции, цена, решение владельца. Ворота `changes` не дают пересобрать
изменившуюся секцию без запроса.

## Формат

Файл `changes/CR-NNN.md`, шапка — YAML между `---`:

```
---
id: CR-001
status: approved        # draft | approved | done | rejected
sections: [home/hero]   # какие секции затронуты
date: 2026-11-08
author: designer
---
```

Дальше — что изменилось и почему.

## Как проверяется

`npm run changes` сравнивает текущий снимок файла с тем, что лежит в git.
Если отпечаток секции изменился, а одобренного запроса (`approved` или `done`)
на неё нет — ворота красные и говорят, какие секции и какой запрос нужен.

Разницу снимков можно посмотреть отдельно: `npm run snapshot:diff A B`.
