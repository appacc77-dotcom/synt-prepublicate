# Контракт спеки: версия схемы и пометка смешанных стилей

Изменение не в макете, а в формате выгрузки. Две правки:

1. **`schemaVersion: 1`** — во все 48 спек. Контракт (`npm run spec:contract`)
   требует версию, чтобы понимать, как читать файл: без неё незнакомая схема
   выглядела бы как «наверное, сойдёт». Содержимое узлов не менялось.
2. **`fontMixed` / `fontSizeMixed`** — четыре секции, где в одном текстовом
   узле смешаны стили (`booking/booking-formats`, `home/quiz`, `practice/quiz`,
   `practice/practice-package`). Раньше такие узлы выгружались с пустым
   шрифтом, и это было неотличимо от забытого поля. Теперь видно, что так
   нарисовано; сам дефект файла остаётся в реестре (FI-5).

Отпечатки секций обновлены `npm run intake --sections-only` — снимок без моста.

Проверено: геометрия и пиксель не менялись, содержимое секций то же.
