# Фон FAQ: cover вместо растяжения

В макете заливка `FILL` — картинка должна обрезаться по центру, а не
растягиваться на всю рамку. В вёрстке стояло `background-size: 100% 100%`,
из-за чего фото сплющивалось.

Заменено на `cover` с центрированием. Проверено воротами `images`: растянутых
картинок нет. Пиксель по секции — 4,31.

Запрос закрыт: правка сделана и проверена.
