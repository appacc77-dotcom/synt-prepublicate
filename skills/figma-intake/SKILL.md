# figma-intake

Первый шаг любой работы с макетом. Отвечает на вопрос «что сейчас в файле» и
«не менялся ли он с прошлого раза».

## Когда брать

- начало сессии по макету;
- макет правили — нужно понять, что именно;
- перед серией экспортов: числа без версии не значат ничего.

## Команда

```bash
npm run intake          # снимок + сводка
npm run intake -- --quiet
```

Читает `design/figma/project.json` (имя файла, `fileKey`, пути) и пишет в
`design/figma/live/`:

| Файл | Что внутри |
|---|---|
| `structure.json` | страницы и верхнеуровневые фреймы с размерами |
| `ds.json` | компоненты, переменные, стили |
| `reality.json` | инстансы по страницам, масштабы, ширины фреймов |
| `snapshot.json` | время, `fileKey`, счётчики по страницам |

## Коды возврата

| Код | Значение | Что делать |
|---|---|---|
| 0 | снимок снят, файл тот | работать дальше |
| 1 | открыт другой файл или `fileKey` не совпал | открыть нужный файл, не подменять конфиг |
| 2 | мост недоступен | открыть Figma и запустить плагин моста |
| 3 | скрипт Figma вернул ошибку | читать сообщение, не выдумывать числа |

## Как читать сводку

**`отмасштабированных: 0`** — дереву можно верить: размер узла равен размеру на
холсте. Любое другое число означает, что часть размеров в дереве не равна
нарисованному, и сверяться нужно с кропом, а не с числом из дерева.

**`фреймов 1440`** — сколько страниц в макете. Ноль или малое число при
нескольких страницах означает, что канонические фреймы не там, где ожидалось.

**Дрейф.** Если с прошлого снимка счётчики изменились, модуль печатает, где:

```
ФАЙЛ МЕНЯЛСЯ с прошлого снимка (2026-11-06T17:00:00.000Z):
   Booking: 99 → 79
   спеки и кропы, снятые раньше, могли устареть.
```

Это не ошибка, а факт: макет редактируют во время работы. Реакция — переснять
`figma-export` для затронутых секций, а не пересобрать вёрстку «на всякий случай».

## Стоп-условия

- `fileKey` не совпал — не править `project.json` под открытый файл: это подмена
  источника;
- мост недоступен — работа останавливается, размеры не берутся из памяти;
- дрейф затронул секцию, которую сейчас собирают — переснять спеку и кроп.
