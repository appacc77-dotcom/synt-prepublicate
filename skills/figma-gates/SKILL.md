# figma-gates

Две проверки с числами. Первая — ворота, вторая — сигнал регрессии.

## Когда брать

- секция собрана и нужно понять, проходит ли она;
- после любой правки вёрстки — чтобы увидеть, не поехало ли;
- перед приёмкой: вердикт выносится по числам, а не по кропу.

## Команды

```bash
npm run build                                              # обязательна: ворота смотрят dist/
npm run measure -- design/figma/pages/<page>/<section>/spec.json  # геометрия, exit 1 при красных
npm run shot -- .<class> .screens/<slug>.png 1440          # снимок элемента
npm run compare -- design/figma/pages/<page>/<section>/crop.png .screens/<slug>.png
```

## Что именно проверяет measure

Элемент с `data-figma-node="<id>"` сверяется с узлом `<id>` из `spec.json` по
четырём числам: `x`, `y`, `w`, `h`. Координаты считаются от корня секции
суммой смещений предков в Figma — разметка вправе отличаться от дерева.

Ширина сверяется у всех узлов, включая текст: текстовые блоки ограничиваются
`max-width` из спеки, поэтому совпадают и ширина, и точки переноса. Если блок
растянут на колонку — ворота это покажут, а не промолчат.

Ворота красные, если:

1. расхождение любого из четырёх чисел больше допуска (по умолчанию 1 px);
2. у узла глубины ≤ 2 нет своего элемента — часть секции не собрана;
3. атрибут ссылается на узел, которого нет в спеке — разметку скопировали.

Допуск меняется через `--tol`, ширина — через `--width`, страница — через `--url`.

## Что показывает compare

Среднюю разницу, долю пикселей с расхождением > 16 и худшие горизонтальные
полосы. Это **не** критерий приёмки: текст растеризуется по-разному у Figma и
браузера, при совпадающих шрифте, кегле и позиции расходится 10–12 % текстовых
пикселей. Фон, заливки и текстуры совпадают до 0,2 %.

Практический ориентир по секции: средняя 1–4, пикселей > 16 — 1–5 %. Если число
выросло вдвое против прошлого прогона — что-то поехало, и это повод смотреть.

## Как читать красное

| Что поехало | Куда смотреть |
|---|---|
| `x`, `y` | `gap`, `align`, лишняя обёртка, `margin` |
| `w` | ширина из контента: шрифт, трекинг, паддинг |
| `h` | интерлиньяж, число строк, вертикальный паддинг |
| узел не найден | забыт `data-figma-node` или неверный id |
| «вне спеки» | атрибут из другой секции |
| пиксель вырос, геометрия зелёная | изменилась картинка, фон, тень или шрифт |

## После зелёного

Числа остаются на диске: `measure` пишет `gate.json`, `compare` — `pixel.json`
рядом с секцией. Публикация — `npm run previews` и `npm run structure`, иначе
страница структуры покажет старые данные.

## Стоп-условия

- три прогона подряд красные по одному и тому же числу — расходится спека или
  шрифт, это не задача вёрстки;
- `measure` падает на «нет dist» — сначала сборка, а не правка вёрстки;
- кроп и спека сняты в разные моменты (файл правили) — переснять через
  `figma-export`, иначе числа сравнивают разное.
