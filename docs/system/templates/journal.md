# Журнал: {{проект}}

Один файл на проект. Пишется человеческим языком — для чтения в перерыве, а не
для отчёта. Технические детали живут в `reports/` и `changes.agent.md`; сюда они
попадают только как вывод.

## Как заполнять

- один блок на шаг или день, не на каждую правку;
- **что сделали** — 2–4 предложения, без пересказа диффа;
- **почему так** — какую альтернативу отвергли и почему;
- **чем заплатили** — время, итерации, что сломалось по дороге;
- **что это меняет** — правило, инструмент или решение, которое появилось;
- артефакты — ссылками, не содержимым.

Если блок невозможно написать без имён свойств и id — это не журнал, а отчёт.
Значит, писать его должен агент, а не продюсер.
