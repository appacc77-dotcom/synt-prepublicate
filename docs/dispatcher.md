# Диспетчер карточек

DSH не разрешает субагенту запускать ещё одного субагента (delegation depth
max 1). Поэтому диспетчер — это не фоновый демон, а **продюсер на расписании**
в этой top-level сессии.

Каждые 3 минуты приходит автоматический тик:

1. читает `kanban_board` и файл `agent-system/dispatch-state.json`;
2. находит карточки в `progress` с `assignee: agent`;
3. если карточки нет в state и активных воркеров меньше 2 — запускает
   субагента по контракту карточки;
4. записывает `cardId → agentId / startedAt` в state;
5. воркер сам переводит карточку в `review` и пишет отчёт; `done` не ставит.

Остановить: удалить напоминание «Диспетчер канбана» через `schedule_delete`
или сказать «останови диспетчер».

Ограничения: это не event-driven демон — задержка до 3 минут; воркер не
закрывает карточку в `done`, это делает приёмка.
