# Как собрать компонент дизайн-системы (E-02)

Порядок проверен на `logo-gold`. Каждый компонент — отдельная карточка.

## 1. Выгрузка

```
node tools/export-section.mjs 29:2054 --name logo-gold
```

Появится `design/figma/pages/design-system/logo-gold/`: `spec.json`, `crop.png`,
`states.json`. Вектор компонента выгружается в `design/figma/assets/svg/` —
экспортёр берёт вектор верхнего уровня, если инстансов-иконок нет.

## 2. Компонент

`src/components/ds/<name>.astro`. Внутри — размеры из спеки, а на элементе:

```
data-figma-node={`${node} 24:1871`}
```

Второй id — вектор внутри компонента: он живёт в том же элементе (это `<img>`
с выгруженным SVG), и без него замер считает узел неразмеченным.

## 3. Ассет

```
cp design/figma/assets/svg/<name>.svg public/svg/
```

Иначе ворота `assets` скажут, что файла нет.

## 4. Страница `/ds`

Импорт, блок с компонентом и имя в списке `built`. Страница собирается из кода.

## 5. Приёмка

```
node tools/measure.mjs design/figma/pages/design-system/<name>/spec.json --url /ds.html
```

Зелёный замер — это и есть приёмка карточки.

**Пиксель для компонентов не применяется:** в файле у них прозрачный фон, а на
странице — фон страницы. Сравнение даёт 229 из 255 на пустом месте. Для
пикселя нужен согласованный фон-подложка — отдельное решение.
