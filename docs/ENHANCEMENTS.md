# Второй слой: первые результаты

Слой дополнений — то, чего в статичном макете нет: поведение, движение,
подсказки. Реестр — `design/enhancements.json`, выключатель — атрибут
`data-enhancements` на `<html>`, сборка без дополнений — `npm run build:base`.

## Что добавлено

### Взаимодействие: курсор и клавиатура

Один язык на весь сайт, длительности из токенов `motion.css`
(160/260/450 мс, `--ease-out`).

| элемент | отклик | зачем |
|---|---|---|
| ссылка | появляется подчёркивание, прозрачность 0.86 | цвет наведения зависит от фона: на тёмном подвале акцентный оттенок давал тёмное на тёмном |
| кнопка, `[role=button]` | подъём на 1 px, мягкая тень; на нажатии тень снимается | отклик на курсор без сдвига раскладки |
| карточка с действием (`.fmt`, `.jcard`, `.pcard`) | подъём на 2 px, тень, 260 мс | видно, что карточка нажимаемая |
| фокус с клавиатуры | кольцо `2px` цвета акцента | доступность: видно, где находится клавиатура |

Все правила под `[data-enhancements='on']`. В сборке «только из макета»
поведение выключено целиком, включая переходы.

## Чего намеренно нет

**Входной анимации страницы.** Она красива, но делает снимок
недетерминированным: `shot` снимает через фиксированное время после `load`,
и кадр может попасть в середину проявления. Пиксельные ворота начали бы
дрожать на ровном месте. Если понадобится — только на внутренних страницах
и с отдельным ожиданием в `shot`.

**Параллакса и прокрутки-анимаций.** Они ломают измерение положения: замер
снимает элемент в его координатах, а параллакс их смещает.

## Как проверяется

| ворота | что смотрят |
|---|---|
| `motion` | у всех видимых интерактивных элементов есть переход; `prefers-reduced-motion` гасит движение у всех |
| `motion-manifest` | каждая анимация в `src/` описана в `design/motion/motion.json` с номером решения |
| `enhancements` | реестр сходится: слой, происхождение, статус, выключатель, связь с изобретённым |
| `enhancement-off` | base-сборка не содержит дополнений |
| `base-parity` | дополнения не изменили основу |
