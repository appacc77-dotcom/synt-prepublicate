# Страница структуры сайта

Внутренняя страница `/structure.html` — карта Syntonia v2 по страницам и блокам.

## Что показывает

- все страницы: главная, метод, мастера, практики, библиотека, booking, quiz,
  юридические/404;
- по каждой странице: маршрут, статус, высота/макет, что уже сделано;
- по каждому блоку: назначение, статус, что осталось, ссылка на страницу;
- для собранных блоков — два превью: эталон и текущая реализация;
- сводка: страниц готово / в работе / не начато, блоков готово / в работе.

## Источники

- `design/export/home/home-1440.png` — Figma-эталон главной;
- `.screens/home-1440.png`, `.screens/method-1440.png` — текущая реализация;
- `design/export/method/method-1440.png` — **не Figma**, а рендер старой сборки
  (помечено на странице);
- extracted-деревья страниц для состава блоков.

## Статусы

- `done` — собрано и принято;
- `review` — собрано и ждёт приёмки;
- `progress` — в работе;
- `todo` — не начато.

## Карточки

`docs/block-cards.json` — манифест карточек: `Home · …` (done),
`Method · …` (progress), `Page · …` (backlog). У каждой карточки ссылка на
`structure.html#block-…`; при расхождении блок перетаскивается в «В работе».

## Приёмка

- `/structure.html` отвечает 200, не входит в публичную навигацию;
- все страницы и блоки перечислены, статусы совпадают с доской;
- у собранных блоков есть два превью, у несобранных — честная заглушка;
- ссылки ведут на локальные маршруты;
- 1440/768/390 без переполнения.
