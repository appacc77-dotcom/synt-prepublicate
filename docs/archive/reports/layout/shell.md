## Что исправлено

1. **Битые якоря.** В меню были `/index.html#voices` и `/index.html#faq`,
   таких id на главной нет. Заменены на существующие
   `/index.html#voices-title` (`Voices.astro:19`) и
   `/index.html#faq-title` (`Faq.astro:46`). Оба перехода прокручивают
   страницу к блоку (числа ниже).
2. **Бургер.** Кнопка теперь **44×44** на всех ширинах (было 38×25 и 32×21).
   Визуальные линии не изменились: 38×25 на десктопе и 32×21 на ≤700 px,
   центр тот же. Линии центрируются flex-контейнером, X собирается через
   `translateY(calc(3px + gap))`. Отрицательный `margin-inline-end`
   (`(ширина линий − 44) / 2` = −3 / −6 px) компенсирует выросшую кнопку,
   поэтому правый край линий остался на прежних x — вид и позиция в шапке
   не сдвинулись.
3. **Закрытие и фокус.** Escape (только при открытом меню), клик вне меню
   (включая пустую область шапки), клик по любой ссылке и повторный клик по
   бургеру закрывают меню. При открытии фокус уходит на первую ссылку; при
   закрытии возвращается на бургер. Tab/Shift+Tab удерживаются внутри меню
   (первая ↔ последняя ссылка, включая CTA). Без библиотек.
4. **Состав меню — по факту.** В меню **7 nav-ссылок + CTA «Личная встреча»,
   всего 8 `<a>`**. Восьмой пункт не добавлялся: решение о нём не принято,
   прежняя формулировка состава была неверной и исправлена.

## Команды

```bash
cd syntonia-v2
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:4321/  # 200
ASTRO_TELEMETRY_DISABLED=1 npm run build                          # 9 page(s), зелёный
ASTRO_TELEMETRY_DISABLED=1 npm run preview                        # 4322, production-проверка
node /tmp/header-check.cjs                                        # замеры 1440/768/390
```

`node /tmp/header-check.cjs` — одноразовый Playwright-скрипт проверки, в
репозиторий не добавлялся (card.files — только `SiteHeader.astro`).
`ASTRO_TELEMETRY_DISABLED=1` нужен из-за sandbox: без него `npm run build`
падает на `EPERM` при записи в `~/Library/Preferences/astro` — это окружение,
не код. Build: `9 page(s) built`. Тот же прогон на `npm run preview` (4322) дал идентичные
числа: бургер 44×44, меню 1424/752/374×475, 8 `<a>`, консоль 0. Preview после
проверки остановлен.

## Остаток и риски

- **Якорь под шапкой исправлен:** в `base.css` добавлен
  `scroll-padding-top: 100px` (78 px на мобилке). Заголовок больше не прячется;
  правка общего слоя, внесена отдельным коммитом.
- **Переход `/` → `/index.html#voices-title`** — полная навигация, фокус
  сбрасывается загрузкой; при переходе с `/index.html` остаётся на бургере.
- **Восьмой пункт меню** не добавлен: 7 nav + CTA — зафиксированный факт,
  расширение состава требует решения владельца.
- `dist/` пересобран build-командой; исходники других компонентов не менялись.
