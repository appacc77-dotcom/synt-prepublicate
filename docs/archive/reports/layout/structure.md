# structure — карта сайта

- маршрут: `/structure.html` (noindex,nofollow)
- источник: `docs/site-structure.md`, данные `src/data/structure.ts`
- назначение: внутренняя карта страниц и блоков, не публичная страница

## Что на странице

- 11 страниц: главная, метод, мастера, практики, библиотека, booking, quiz,
  оферта, политика, согласие, 404;
- 45 блоков страниц + 2 общих (шапка, подвал);
- статусы `готово / на приёмке / в работе / не начато`;
- для home/method — Figma; для остальных собранных блоков — старая сборка
  и сделано; у journal-шаблонов превью нет;
- ссылки на локальные маршруты;
- статусы и счётчики обновляются с канбана каждые 2,5 с (как `/progress.html`),
  статический снимок остаётся fallback;
- Method честно помечен: эталон — рендер старой сборки, не Figma.
